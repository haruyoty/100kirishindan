# 789P38 100切り診断

ゴルフの「789P38理論」の4つの技術から、**100切りまであと何打か**を診断するツールです。
直近1ラウンドの数字を5つ入れると、その技術のまま18ホールを4000回シミュレーションし、
何回100を切れるかを出します。

## 789P38理論

| | 技術 | 基準 |
|---|---|---|
| **7** | ドライバーを打ったら、7割方グリーンを狙える所に置ける | 14ホール中10ホール |
| **8** | アイアンを持ったら、残り50ヤードまで運べる | 14ホール中12ホール |
| **9** | 50ヤード以内は、9割方グリーンに乗せられる | 打った回数の9割 |
| **38P** | 18ホール回って、38パット以内に収められる | 38パット以下 |

## 使い方

1. 直近ラウンドの数字を5つ入力する
2. コース図で、どこで打数をこぼしているかを見る（○＝基準クリア／×＝未達）
3. 一番下の「次に直すべき1本」を練習する

扇形の広がり・弾道の長さ・グリーン上の円は、入力した数字に連動して変わります。

## 中身について

- 依存ライブラリなし。`index.html` 1枚で完結し、オフラインでも動きます
- スコアは近似式ではなく、1打ずつ抽選する18ホールのシミュレーションから算出
- 同じ入力なら毎回同じ結果になるよう乱数を固定
- 基準をちょうど満たす技術で平均98.5打になるよう較正（誤差0.03打以内で検証済み）

コース難易度・距離・天候・傾斜は考慮していません。4つの技術だけから見た計算結果です。
